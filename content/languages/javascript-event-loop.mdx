## Interview prompt

Call stack, task queue, microtask queue এবং event loop-এর সম্পর্ক ব্যাখ্যা করো।

## Explanation বাংলায়

Synchronous stack আগে চলে। Stack empty হলে microtasks যেমন Promise callbacks সাধারণত পরবর্তী task-এর আগে drain হয়; timers ও I/O callback task scheduling-এর মাধ্যমে পরে চলে। Exact host details browser ও Node.js-এ কিছুটা আলাদা।

## Example

```javascript
console.log("start");
setTimeout(() => console.log("timer"), 0);
Promise.resolve().then(() => console.log("promise"));
console.log("end");
```

সাধারণ browser runtime-এ output order: start, end, promise, timer। Synchronous log আগে হয়, Promise callback microtask, timer callback পরে task হিসেবে চলে।

## Common mistakes

- setTimeout(..., 0) immediate execution বোঝায় না।
- Microtask loop অনবরত চললে rendering starve করতে পারে।
- Node event loop phases browser-এর সঙ্গে এক নয়।

## Interview-ready answer

প্রথমে concept-টি এক বা দুই বাক্যে সংজ্ঞায়িত করো। তারপর code/runtime-এর ছোট example, trade-off এবং একটি failure case বলো। Performance claim করলে কোন runtime/version বা workload ধরে বলছ তা স্পষ্ট করো; implementation-specific behavior-কে সব language-এর নিয়ম হিসেবে উপস্থাপন কোরো না।
