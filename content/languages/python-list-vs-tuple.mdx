## Interview prompt

Python list এবং tuple-এর মধ্যে পার্থক্য, ব্যবহার এবং mutability-এর প্রভাব ব্যাখ্যা করো।

## Explanation বাংলায়

List mutable, তাই append বা item assignment করা যায়। Tuple immutable sequence; fixed record বা hashable collection key হিসেবে কাজে লাগতে পারে যদি সব element hashable হয়। Tuple-এর immutability shallow—এর ভেতরে mutable object থাকলে সেটি বদলাতে পারে।

এখানে list-এর structure mutate করা যায়; tuple-এর element binding পরিবর্তন করা যায় না, কিন্তু tuple-এর মধ্যে থাকা mutable object এখনও mutate হতে পারে।

## Common mistakes

- Tuple nested mutable object-কে immutable বানায় না।
- List সাধারণত dictionary key হতে পারে না।
- Performance difference সাধারণত semantics-এর চেয়ে কম গুরুত্বপূর্ণ।
