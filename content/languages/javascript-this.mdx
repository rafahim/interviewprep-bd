## Interview prompt

Regular function এবং arrow function-এ `this` কীভাবে নির্ধারিত হয়?

## Explanation বাংলায়

Regular function call-site অনুযায়ী this পায়—method call, explicit bind/call/apply, constructor বা strict-mode standalone call। Arrow function নিজস্ব this bind করে না; lexical surrounding scope থেকে নেয়।

## Example

```javascript
const user = {
  name: "Fahim",
  showName() {
    return this.name;
  }
};

const show = user.showName;
console.log(user.showName());
console.log(show());
```

প্রথম call-এ receiver `user`; detached regular function-এ strict mode-এ `this` undefined হতে পারে। Callback হিসেবে ব্যবহার করতে চাইলে bind বা arrow closure context বুঝে বেছে নাও।

## Common mistakes

- Function কোথায় লেখা হয়েছে তা সবসময় regular function-এর this নির্ধারণ করে না।
- Arrow function method হিসেবে সাধারণত উপযুক্ত নয় যদি dynamic this দরকার হয়।
- Class method callback-এ binding খেয়াল করতে হবে।
