## Interview prompt

Browser/CDN cache কীভাবে latency কমায় এবং stale content নিয়ন্ত্রণ করে?

## Explanation বাংলায়

Cache-Control freshness ও shared/private caching নির্দেশ করে; ETag conditional request-এ resource unchanged হলে 304 দেয়। Hashed static assets long immutable cache পেতে পারে, কিন্তু personalized response public cache-এ দেওয়া বিপজ্জনক।

## Example

```http
Cache-Control: public, max-age=31536000, immutable
ETag: "asset-v3-a83f"

If-None-Match: "asset-v3-a83f"
```

Fingerprint URL-সহ versioned static asset দীর্ঘদিন cache করা যায়। ETag validator দিয়ে stale response revalidation করা যায়; personalized data public cache করা উচিত নয়।

## Common mistakes

- Authorization/personal data cache policy সতর্কভাবে করতে হবে।
- ETag validation freshness policy-এর বিকল্প নয়।
- Versioned asset URL invalidation সহজ করে।
