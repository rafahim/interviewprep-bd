## Interview prompt

Promise chain ও async/await দিয়ে asynchronous error handling এবং parallel task management বোঝাও।

## Explanation বাংলায়

async function সবসময় Promise ফেরত দেয়। await rejection হলে try/catch-এ ধরা যায়। Independent operation sequential await না করে Promise.all-এ চালালে wall-clock latency কমতে পারে, কিন্তু Promise.all fail-fast এবং cancellation নিজে থেকে করে না।

## Example

```javascript
async function loadDashboard() {
  const [profileResponse, statsResponse] = await Promise.all([
    fetch("/api/profile"),
    fetch("/api/stats")
  ]);
  if (!profileResponse.ok || !statsResponse.ok) {
    throw new Error("Dashboard request failed");
  }
  return Promise.all([profileResponse.json(), statsResponse.json()]);
}
```

দুইটি independent fetch একসঙ্গে শুরু হয়। Response status check, exception handling এবং প্রয়োজন হলে AbortController দিয়ে cancellation যোগ করতে হবে।

## Common mistakes

- await সব operation parallel করে না।
- Promise.all partial results return করে না যখন reject হয়।
- Unhandled rejection logging ও cleanup দরকার।

## Interview-ready answer

প্রথমে concept-টি এক বা দুই বাক্যে সংজ্ঞায়িত করো। তারপর code/runtime-এর ছোট example, trade-off এবং একটি failure case বলো। Performance claim করলে কোন runtime/version বা workload ধরে বলছ তা স্পষ্ট করো; implementation-specific behavior-কে সব language-এর নিয়ম হিসেবে উপস্থাপন কোরো না।
