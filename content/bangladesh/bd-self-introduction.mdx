## Interview prompt

বাংলাদেশের software company-তে junior web developer interview-তে 60–90 সেকেন্ডের পরিচয় কীভাবে দেবে?

## বাংলায় প্রস্তুতি

বাংলা বা ইংরেজি—যে ভাষায় interview চলছে সেই ভাষায় structured introduction দাও: current focus, relevant skills, one concrete project, target role-এ আগ্রহ। CV-এর বাইরে অপ্রাসঙ্গিক ব্যক্তিগত তথ্য বাদ রাখো।

## Sample answer

> আমি web development-এ focus করছি এবং frontend, API integration ও responsive UI নিয়ে hands-on project করেছি। একটি project-এ আমার কাজ ছিল [নিজের feature]-এর implementation, testing এবং bug fixing। এখন এমন team-এ কাজ করতে চাই যেখানে maintainable software ship করার পাশাপাশি code review থেকে শিখতে পারব।

এই নমুনার square-bracket অংশগুলো নিজের সত্য তথ্য দিয়ে বদলাও। ভিন্ন ভাষায় interview হলেও answer-এর core message একই রাখো এবং technical term প্রয়োজনমতো English-এ ব্যবহার করো।

## Bangladesh-specific checklist

- যে experience নেই তা দাবি কোরো না।
- Company-এর কাজ না জেনে generic praise দিও না।
- বাংলা-ইংরেজি technical vocabulary স্বাভাবিকভাবে ব্যবহার করতে পারো।

## Follow-up questions প্রস্তুত করো

Interviewer যদি “একটি উদাহরণ দাও”, “কেন এমন সিদ্ধান্ত নিলে?” বা “আবার করলে কী বদলাবে?” জিজ্ঞেস করেন, তখন claim-এর সঙ্গে বাস্তব project, document, test, communication বা decision-এর evidence দেখাও। Salary, joining date বা experience-এর ক্ষেত্রে যাচাই করা তথ্যই বলো।
