## Problem

প্রতিবার 1 বা 2 ধাপ নেওয়া গেলে n ধাপের সিঁড়িতে ওঠার মোট distinct উপায় গণনা করো।

## Example

**Input:** `n = 4`

**Output:** `5`

## Approach বাংলায়

শেষে পৌঁছানো যায় n-1 ধাপ থেকে 1 step অথবা n-2 ধাপ থেকে 2 steps নিয়ে। তাই recurrence Fibonacci: ways[n] = ways[n-1] + ways[n-2]।

শেষ ধাপের আগের অবস্থান n-1 বা n-2; তাই দুইটি আগের count যোগ হয়। কেবল দুইটি state রাখায় extra space constant।

## Python solution

```python
def climb_stairs(n):
    if n <= 2:
        return n
    one, two = 1, 2
    for _ in range(3, n + 1):
        one, two = two, one + two
    return two
```

## JavaScript solution

```javascript
function climbStairs(n) {
  if (n <= 2) return n;
  let one = 1;
  let two = 2;
  for (let step = 3; step <= n; step += 1) {
    const next = one + two;
    one = two;
    two = next;
  }
  return two;
}
```

## Complexity analysis

- **Time:** O(n) — প্রতিটি item কতবার process হয় এবং sorting/heap থাকলে তার cost হিসাব করো।
- **Extra space:** O(1) — input বাদে তৈরি করা auxiliary structure-এর ব্যবহার এই হিসাবে ধরা হয়েছে।

## Edge cases

- n অন্তত 1।
- Base case ways[1]=1, ways[2]=2।
- বড় n-এর জন্য language integer overflow খেয়াল রাখতে হবে।
