## Problem

দুইটি ascending sorted linked list দেওয়া আছে। একই sorted order-এ merge করে head ফেরত দাও।

## Example

**Input:** `list1 = [1, 2, 4], list2 = [1, 3, 4]`

**Output:** `[1, 1, 2, 3, 4, 4]`

## Approach বাংলায়

একটি dummy node ও tail pointer নাও। দুই list-এর ছোট node-টি tail-এর সঙ্গে যুক্ত করে সংশ্লিষ্ট pointer এগিয়ে নাও; শেষে বাকি অংশ যুক্ত করো।

দুই list sorted হওয়ায় তাদের head-এর ছোট node-টিই পুরো অবশিষ্ট অংশের সবচেয়ে ছোট candidate। Dummy node প্রথম insertion-এর special case বাদ দেয়।

## Python solution

```python
def merge_two_lists(list1, list2):
    dummy = ListNode(0)
    tail = dummy
    while list1 and list2:
        if list1.val <= list2.val:
            tail.next = list1
            list1 = list1.next
        else:
            tail.next = list2
            list2 = list2.next
        tail = tail.next
    tail.next = list1 if list1 else list2
    return dummy.next
```

## JavaScript solution

```javascript
function mergeTwoLists(list1, list2) {
  const dummy = new ListNode(0);
  let tail = dummy;
  while (list1 !== null && list2 !== null) {
    if (list1.val <= list2.val) {
      tail.next = list1;
      list1 = list1.next;
    } else {
      tail.next = list2;
      list2 = list2.next;
    }
    tail = tail.next;
  }
  tail.next = list1 !== null ? list1 : list2;
  return dummy.next;
}
```

## Complexity analysis

- **Time:** O(n + m) — প্রতিটি item কতবার process হয় এবং sorting/heap থাকলে তার cost হিসাব করো।
- **Extra space:** O(1) — input বাদে তৈরি করা auxiliary structure-এর ব্যবহার এই হিসাবে ধরা হয়েছে।

## Edge cases

- একটি বা দুইটি list-ই খালি হতে পারে।
- মূল node-গুলো reuse করা যায়।
- দুই value সমান হলে যেকোনো list-এর node আগে আসতে পারে।

## Interview follow-up

প্রথমে brute-force approach এবং তার complexity ব্যাখ্যা করো, তারপর optimized approach কেন কাজ করে তার invariant বলো। এরপর input size, duplicate, empty input এবং worst-case memory নিয়ে interviewer-এর সঙ্গে কথা বলো।
