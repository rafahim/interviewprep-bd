## Problem

Integer array-তে কোনো value একাধিকবার থাকলে true, নইলে false ফেরত দাও।

## Example

**Input:** `nums = [1, 2, 3, 1]`

**Output:** `true`

## Approach বাংলায়

Set-এর মধ্যে value রাখো। কোনো value আগে থেকেই set-এ থাকলে duplicate পাওয়া গেছে; না থাকলে সেটি যোগ করো।

Set membership একটি value আগে দেখা হয়েছে কি না দ্রুত জানায়। Duplicate পাওয়া মাত্র early return করা যায়।

## Python solution

```python
def contains_duplicate(nums):
    seen = set()
    for value in nums:
        if value in seen:
            return True
        seen.add(value)
    return False
```

## JavaScript solution

```javascript
function containsDuplicate(nums) {
  const seen = new Set();
  for (const value of nums) {
    if (seen.has(value)) return true;
    seen.add(value);
  }
  return false;
}
```

## Complexity analysis

- **Time:** O(n) average — প্রতিটি item কতবার process হয় এবং sorting/heap থাকলে তার cost হিসাব করো।
- **Extra space:** O(n) — input বাদে তৈরি করা auxiliary structure-এর ব্যবহার এই হিসাবে ধরা হয়েছে।

## Edge cases

- Empty array-তে duplicate নেই।
- Negative integer-ও সাধারণ value।
- Set operation average O(1), worst-case implementation-dependent।

## Interview follow-up

প্রথমে brute-force approach এবং তার complexity ব্যাখ্যা করো, তারপর optimized approach কেন কাজ করে তার invariant বলো। এরপর input size, duplicate, empty input এবং worst-case memory নিয়ে interviewer-এর সঙ্গে কথা বলো।
