## Problem

Ascending sorted array এবং target দেওয়া আছে। target-এর index বের করো; না থাকলে -1 ফেরত দাও।

## Example

**Input:** `nums = [-1, 0, 3, 5, 9, 12], target = 9`

**Output:** `4`

## Approach বাংলায়

low ও high দিয়ে search interval রাখো। মধ্যবর্তী value target-এর সমান হলে return; ছোট হলে low বাড়াও, বড় হলে high কমাও।

প্রতিটি comparison-এ অর্ধেক search interval বাদ যায়। Loop condition low <= high একটিমাত্র সম্ভাব্য index-ও পরীক্ষা করতে দেয়।

## Python solution

```python
def binary_search(nums, target):
    low, high = 0, len(nums) - 1
    while low <= high:
        mid = low + (high - low) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

## JavaScript solution

```javascript
function binarySearch(nums, target) {
  let low = 0;
  let high = nums.length - 1;
  while (low <= high) {
    const mid = low + Math.floor((high - low) / 2);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) low = mid + 1;
    else high = mid - 1;
  }
  return -1;
}
```

## Complexity analysis

- **Time:** O(log n) — প্রতিটি item কতবার process হয় এবং sorting/heap থাকলে তার cost হিসাব করো।
- **Extra space:** O(1) — input বাদে তৈরি করা auxiliary structure-এর ব্যবহার এই হিসাবে ধরা হয়েছে।

## Edge cases

- Array sorted হতে হবে।
- Empty array হলে -1।
- Mid হিসাবের overflow এড়াতে low + (high - low) // 2 প্যাটার্ন ব্যবহার করা যায়।
