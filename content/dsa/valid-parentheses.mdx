## Problem

বন্ধনীযুক্ত string-এ (), [], {} সঠিকভাবে nested ও matched কি না নির্ধারণ করো।

## Example

**Input:** `s = "{[]}"`

**Output:** `true`

## Approach বাংলায়

Opening bracket stack-এ রাখো। Closing bracket এলে stack ফাঁকা কি না এবং top-এর bracket matching কি না পরীক্ষা করো। শেষে stack খালি হলে string valid।

Stack-এর top-ই সর্বশেষ unmatched opening bracket। Closing bracket-এর type top-এর সঙ্গে না মিললে আর কোনো ভবিষ্যৎ character সেটি ঠিক করতে পারবে না, তাই সঙ্গে সঙ্গে false।

## Python solution

```python
def is_valid(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for char in s:
        if char in '([{':
            stack.append(char)
        elif not stack or stack.pop() != pairs.get(char):
            return False
    return not stack
```

## JavaScript solution

```javascript
function isValid(s) {
  const pairs = { ")": "(", "]": "[", "}": "{" };
  const stack = [];
  for (const char of s) {
    if (char === "(" || char === "[" || char === "{") stack.push(char);
    else if (stack.length === 0 || stack.pop() !== pairs[char]) return false;
  }
  return stack.length === 0;
}
```

## Complexity analysis

- **Time:** O(n) — প্রতিটি item কতবার process হয় এবং sorting/heap থাকলে তার cost হিসাব করো।
- **Extra space:** O(n) — input বাদে তৈরি করা auxiliary structure-এর ব্যবহার এই হিসাবে ধরা হয়েছে।

## Edge cases

- খালি string valid।
- শুধু closing bracket থাকলে invalid।
- ভিন্ন ধরনের bracket ভুলভাবে match হতে পারবে না।
